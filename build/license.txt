DeepSeek Harness 桌面（dsh-desktop）安装协议与安全提示

========================================
一、软件性质
========================================
1. 本软件是 DeepSeek Harness（dsh）的桌面管理壳，仅提供本地服务托管、工作区、技能（Skills）与 MCP 管理功能。
2. 本软件为非官方工具，与 DeepSeek 官方无隶属关系。

========================================
二、安全提示
========================================
1. 本软件不含任何账号凭据，不会收集或上传您的聊天记录、API Key 或任何本地数据。
2. 您的 API Key 仅保存在本机（DSH_HOME 目录下的 .credentials.yaml），请勿向他人泄露该文件。
3. “帮我安装”功能会通过 npm 从官方源下载 dsh 及其依赖，请确保网络环境可信。
4. 请从可信渠道获取本安装包，勿安装来源不明的修改版。

========================================
三、使用条件
========================================
1. 使用本软件前，请确认已安装 Node.js（22.19 及以上版本，推荐 24+）。
2. 使用 dsh 需要您自行准备有效的 DeepSeek API Key。

DeepSeek Harness 桌面 使用说明

一、首次启动
1. 双击桌面“DeepSeek Harness 桌面”图标启动。
2. 若提示“未识别到用户已安装 DeepSeek Harness（dsh）”：
   点“帮我安装 DeepSeek Harness”自动安装（需已装 Node.js 22.19+ 或 24+，
   走国内镜像源，速度快）；
   或点“选择 DeepSeek Harness 已安装的目录文件”手动指定
   （选择包含 node_modules\@deepseek-ai\dsh 的安装目录，如 D:\deepseek-harness）；
   或自行安装 dsh 后点“重试”。
3. 未安装 Node.js？打开官网 https://nodejs.org/zh-cn/download
   下载 LTS 版本安装（一路下一步即可）；应用内提示处也有快捷链接。
4. 自动安装需要几分钟并保持网络畅通，安装进度会在页面实时显示。

二、登录
1. 首次进入工作台后，在页面内“模型”设置处填写您自己的 DeepSeek API Key。
2. Key 仅保存在本机，卸载本软件不会删除 dsh 数据（数据在数据目录中，需手动删除）。

三、常用操作
1. 关闭窗口 = 最小化到系统托盘；右键托盘鲸鱼图标可退出。
2. 托盘鲸鱼图标变红 = 服务异常；蓝色 = 运行中。
3. Ctrl+Shift+D 打开控制面板：管理工作区、技能（Skills）、MCP 开关与导入。
4. 控制面板中“检查更新”可获取新版本（有新版本时自动弹更新确认窗）。
5. 控制面板“🎨 皮肤”可自定义工作台背景图片（支持 png/jpg/webp/gif）。

四、更新（桌面端与 dsh 本体）
1. 每次启动自动检测新版本；检测到新版本会弹更新确认窗（含更新内容说明），
   并同时发系统通知，点通知可打开控制面板。
2. 更新弹窗内可自选更新源：
   - 国内镜像（阿里 npmmirror）：快、稳定，推荐日常使用；
   - 官方源：原汁原味，但可能受网络波动影响下载失败，失败时建议改用镜像。
3. 更新过程中弹窗实时显示进度；长时间无进展会显示卡住警示，
   卡死超过 2 分半会自动重试一次，无需手动干预。
4. 更新失败时，失败页会显示原因与建议；可点【重试】再次更新，
   或关闭后在控制面板点“更新失败 点此重试”重新发起。
5. 桌面端 APP 更新：下载完成后弹“已更新完成，请重启桌面端”，
   点【立即重启】自动打开安装包（覆盖安装，配置与数据保留）。

五、注意事项
1. 遇到 dsh 服务异常时：请完全退出应用（托盘右键 → 退出）后重新进入一次。
2. 不要随意分享 DSH_HOME 数据目录（默认 D:\deepseek-harness\home），
   其中包含您的 API Key 和全部聊天记录。
3. 更换 API Key 请在 Web UI 内操作，不要手动编辑 .credentials.yaml。
4. 若 3080 端口被其他程序占用，可修改配置文件中的 port 值后重启应用。
